# Changelog

What a visitor to the acuteping page can see changed in each release of this
repository, newest first.

## 0.2.0 - 2026-11-27

- The page is now the sonar geometry calculator: side imaging, down imaging,
  2D and live sonar geometry, with your transducers, depth and beam angles set
  once in Settings. It replaces the starter example that showed a sum.
- The footer of the page links to this repository, its licence text and this
  changelog.
- The source holds the calculator's code, its unit tests and its browser tests.

## 0.1.0 - 2026-11-24

- First published version of the source. The page is a starter example that
  shows a sum; it does not calculate sonar geometry yet.
