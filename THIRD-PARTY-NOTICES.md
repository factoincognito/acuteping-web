What the build puts into `dist/` (read 2026-11-26 on the branch of the cut-over, with `npm ci` and `npm run build`; the result is the calculator, built from `index.html` and `src/`): `dist/index.html` is one file of 219,058 bytes. Its style is the style of `index.html`, byte for byte: `vite.config.mts` turns the CSS minifier off, so lightningcss transforms nothing and the output holds none of its custom properties. Its inline script is the modules of `src/`, which are ours, minified and wrapped in one function by rolldown (1.2.19, MIT, vite's bundler), after the line `"use strict";` that `vite.config.mts` sets; the module-preload polyfill that vite adds to a module script is not in it (`modulePreload: false`; the text `modulepreload` does not occur in the file). Whether the wrapper and what the minifier writes carry a licence or notice the page has to show was not read and is open, as before. That build produced only `dist/index.html`, and nothing from `legacy/` is in it.
